# 🖥 앱 개발사 콘솔 샘플 — 사용량 · 시뮬레이터

여러분의 앱 키로 **내 앱의 사용량**을 보고 **전화 없이 앱을 시험**하는 작은 웹 화면입니다(DVG 1.4.16.259+).
그대로 써도 되고, 여러분의 관리 화면에 옮겨 붙여도 됩니다.

```
브라우저 ──▶ 콘솔 서버(이 폴더 · 앱 키 보관) ──앱 키──▶ DVG
             화면 파일 · 요청 세 가지만 넘김
```

| 위젯 | DVG API | 보이는 것 |
|---|---|---|
| `app` 🧩 앱 정보 | `GET /api/v1/apps/self` | 이름 · 켜짐 · 설치된 회사 수 · 월 상한 · 연결 주소 · 키 끝 4자리 |
| `usage` 📊 사용량 | `GET /api/v1/apps/self/usage?month=` | 통화 수 · 사람에게 연결된 비율 · 결말별 · 연결 시간 · 음성인식 초 · 음성합성 글자 · 주소 풀이 · 월 상한 |
| `simulate` 🧪 시뮬레이터 | `POST /api/v1/apps/self/simulate` | 발신자 발화를 넣으면 DVG 가 **여러분의 앱에 실제로 연결해** 대화를 돌리고 글자로 보여 줌 |

## 실행

Node.js 20+ · 외부 패키지 없음.

1. 앱 키(`dvga_…`)를 **한 줄만** 담은 파일을 만듭니다. 권한은 본인만 읽게 합니다.

   ```bash
   cat > "$HOME/dvg-app.key"
   ```

   키를 붙여 넣고 Enter · Ctrl+D 를 누른 뒤:

   ```bash
   chmod 600 "$HOME/dvg-app.key"
   ```

2. 콘솔을 띄웁니다.

   ```bash
   DVG_BASE_URL=https://dvg.example.com:8443 DVG_APP_KEY_FILE="$HOME/dvg-app.key" node server.mjs
   ```

3. 브라우저에서 `http://127.0.0.1:8790` 을 엽니다.

| 환경변수 | 기본값 | 뜻 |
|---|---|---|
| `DVG_BASE_URL` | (필수) | DVG 주소 — **https** 로. 평문이면 앱 키가 암호화 없이 오가므로 시작할 때 경고합니다 |
| `DVG_APP_KEY_FILE` | (필수) | 앱 키 파일. 키는 이 서버 안에만 있고 화면으로 가지 않습니다 |
| `HOST` · `PORT` | `127.0.0.1` · `8790` | 콘솔 주소 |
| `CONSOLE_PASSWORD` | (없음) | 화면 비밀번호(HTTP Basic). **`HOST` 가 이 컴퓨터 밖에서 열리는 값이면 필수** — 없으면 시작하지 않습니다 |
| `CONSOLE_WIDGETS` | `app,usage,simulate` | 보일 위젯과 순서. 예: `usage` 만 |

## 지키는 것

- 🔑 **앱 키를 브라우저에 두지 않습니다.** 화면 코드에 키를 넣으면 화면을 여는 누구나 키를 가져갑니다. 그래서 작은 서버가 키를 들고 대신 부릅니다.
- 🚧 **넘기는 경로는 셋뿐입니다**(`server.mjs` 의 `ROUTES`). 이 서버는 아무 주소나 대신 불러 주는 프록시가 아닙니다. DVG 가 리다이렉트해도 따라가지 않습니다(키가 다른 곳으로 가지 않게).
- 0️⃣ **「0」과 「모름」을 섞지 않습니다.**
  - 이 달 기록이 없으면 «0건» 이 아니라 **«아직 없음»**
  - 장부를 못 읽으면 **«모름»**
  - 수량을 몰랐던 통화가 있으면 음성인식·음성합성 합계에 **«최소값»** 표시
  - 합계 정합 판정(`complete`)은 DVG 가 한 것을 그대로 씁니다
- 🗓 **달은 UTC 기준**입니다(DVG 장부가 UTC 로 자릅니다). 한국 시간 1일 오전 9시 전 통화는 전달에 들어갑니다.
- 🧪 **시뮬레이터는 사용량에 세지 않습니다.** 앱은 그때 `setup.simulated:true` 를 받으니 **실제 주문을 만들지 마십시오.**
  음성이 아니라 글자 시험이라 음성인식 오인식·무음 판정·끼어들기는 재현되지 않습니다. 앱당 분당 20회까지입니다.
- 🛡 화면은 글자를 언제나 `textContent` 로 넣습니다(대화 기록에는 앱과 발신자의 말이 그대로 들어옵니다). CSP 는 `default-src 'self'` 입니다.

## 위젯 더하기

`public/widgets/<이름>.js` 파일 하나가 위젯 하나입니다. `mount(card, ctx)` 를 내보내면 됩니다.

```js
// public/widgets/hello.js
import { h, put } from '../lib/dom.js';
export async function mount(card, ctx) {
  const { status, body } = await ctx.self(); // 앱 정보(한 번만 불러 나눠 씀)
  put(card, h('h2', {}, '안녕'), h('p', {}, status === 200 ? body.app.name : '앱 정보를 받지 못했습니다'));
}
```

`server.mjs` 의 `ALL_WIDGETS` 에 이름을 넣고 `CONSOLE_WIDGETS` 로 고릅니다. 새 DVG API 를 부르려면 `ROUTES` 에도 한 줄 더해야 합니다(콘솔이 넘기는 경로는 거기 적힌 것뿐입니다).

⚠️ **통화 기록(대화·발신번호·주소)은 이 콘솔에 없습니다** — 앱 키로는 열려 있지 않습니다(운영사 관리자 화면에만 있습니다).

## 시험

```bash
npm test
```

가짜 DVG 를 띄워 실제 HTTP 로 확인합니다: 키가 응답·설정에 새지 않는가 · 셋 말고는 넘기지 않는가 · 리다이렉트를 따라가지 않는가 ·
`public/` 밖 파일을 주지 않는가 · 달 형식 · 본문 크기 · 비밀번호 · 「0」과 「모름」 · 화면 코드가 `innerHTML` 을 쓰지 않는가.
