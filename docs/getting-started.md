# 시작하기 — DVG 음성 앱 만들기

## 0. 한눈에

1. **등록 받기** — DVG 운영사에 앱 id·연결 주소(`ws(s)://…`)를 알리면 **앱 키**와 **서명 비밀**을 한 번 받습니다.
2. **앱 띄우기** — 연결 주소에서 WebSocket 을 엽니다. [예제](../examples/)를 그대로 시작점으로 쓰면 됩니다.
3. **시험** — 전화 없이 [시험 API](#4-시험하기)로 대화를 끝까지 돌려 봅니다.
4. **설치** — 운영사가 주문 회사에 앱을 설치하면 그 회사로 오는 전화를 앱이 응대합니다.

## 1. 언어

아무 언어나 됩니다. 필요한 것은 ① WebSocket 서버 ② JSON ③ HMAC-SHA256 뿐입니다. 서명 구현이 맞는지는 [적합성 시험 벡터](../conformance/vector.json)로 확인하십시오. 예제는 [Python](../examples/python/) · [Node.js](../examples/node/) · [Go](../examples/go/) 세 가지이고 동작이 같습니다.

## 2. 어디에서 돌리나 — 다른 서버 / **DVG 와 같은 서버**

| 형태 | 연결 주소 예 | 맞는 경우 |
|---|---|---|
| **다른 서버** | `wss://app.example.com/dvg-relay` | 개발사가 자기 인프라에서 운영 · 여러 DVG 가 한 앱을 쓸 때 |
| **같은 서버**(DVG 와 한 대) | `ws://127.0.0.1:19999/relay` | 작은 고객 · 서버를 한 대로 끝내고 싶을 때 |

⚠️ 앱은 어느 경우든 **DVG 프로세스 밖**에서 돕니다 — 앱이 죽어도 그 앱이 맡은 통화만 사람에게 넘어가고 게이트웨이는 영향을 받지 않습니다.

### 2-1. 같은 서버 — DVG 가 띄우는 사이드카(DVG 1.4.16.262+)

운영사가 사이드카를 켜면 **DVG 가 앱 프로세스를 띄우고 지켜봅니다.** 앱 쪽에서 할 일은:

- 실행 파일 하나(`run`)를 운영사에 전달합니다 — 셸 스크립트·파이썬·Node·바이너리 무엇이든.
- 아래 환경변수를 읽습니다(예제 둘 다 이미 읽습니다):

| 이름 | 뜻 |
|---|---|
| `DVG_APP_ID` | 앱 id |
| `DVG_APP_SIGNING_SECRET` | 서명 비밀 — 키를 재발급하면 DVG 가 앱을 **자동으로 다시 시작**해 새 값을 넣습니다 |
| `DVG_APP_HOST` · `DVG_APP_PORT` · `DVG_APP_PATH` | 열어야 할 주소 |
| `DVG_APP_DATA_DIR` | 앱이 쓸 수 있는 **유일한** 디렉터리(재시작해도 남는다) |
| `DVG_API_BASE` | 앱 자기 조회 API 주소(루프백) |
| (운영사가 넣은 값) | 업무 시스템 자격증명 등 앱이 쓸 비밀 |

사이드카는 격리된 환경에서 돕니다 — 일회용 사용자 · 읽기 전용 파일 시스템(쓰기는 `DVG_APP_DATA_DIR`·`/tmp` 만) · DVG·PBX 디렉터리 접근 불가 · 메모리 512MB · 프로세스 256개. **앱은 `DVG_APP_DATA_DIR` 밖에 파일을 쓰지 않게** 만드십시오.

## 3. 대화 규칙 — 이것만 지키면 됩니다

| 규칙 | 이유 |
|---|---|
| **DVG 메시지 하나에 지시 하나**(엄격한 요청·응답) | `setup`·`said`·`prompt`·`error` 를 받을 때마다 `say`·`ask`·`transfer`·`hangup` 중 **하나**를 보낸다 |
| **10초 안에** 답한다 | 넘기면 통화가 사람에게 간다(`app_error`). 업무 API 호출이 느리면 먼저 `say`(「확인하겠습니다」)로 시간을 번다 |
| **서명·타임스탬프를 확인**한다 | 틀리거나 ±300초를 벗어나면 연결을 받지 않는다 — 주소를 알아낸 제3자가 가짜 통화를 흘려 넣지 못하게 |
| 답이 정해진 질문은 **`choices` 를 함께** 보낸다 | DVG 가 답을 선택지로 읽어 준다(짧게 뭉개진 「참불」 도 초성으로 «착불») — `confirm:true` 면 **복창해 확인**받는다 |
| 주소는 **`expect:"address"`** 로 묻는다 | DVG 가 시·도/구·군/동으로 풀어 준다. 여러 곳이면 `address.question` 을 **글자 그대로** 다시 묻는다(그래야 다음 답을 좁혀 준다) · 확정 전 **복창** — 계약 §3-5 |
| `ask` 는 **질문**, `say` 는 **안내** | `ask` 는 말하다가 발신자가 끼어들면 멈추고 답을 듣는다. `say` 는 끝까지 말한다 |
| **같은 질문을 되풀이하지 않는다** | 다시 물을 때는 **질문을 바꾼다** — 같은 문장 세 번은 발신자를 화나게 한다 |
| 나열·복창은 **마침표로 끊는다** | 「출발 강남역. 도착 서초동. 결제 착불.」 — 쉼표로 이으면 전화에서 한 덩어리로 들린다 |
| 발신자를 탓하지 않는다 | ❌ 「잘 안 들리시네요」 ✅ 「제가 잘 못 들었습니다」 |
| 사람 연결 번호를 정하지 않는다 | `transfer` 는 운영사가 정한 번호로만 간다(통화료 사기 방지) |
| AI 고지를 하지 않는다 | DVG 가 앱보다 먼저 이미 했다(`setup.noticePlayed`) |
| `setup.simulated` 가 `true` 면 **실제 주문을 만들지 않는다** | 전화 없는 시험이다 |

업무 시스템 API(주문 등록 등)는 **앱이 직접** 부릅니다 — DVG 는 중계하지 않습니다. `setup` 의 `orgId`(주문 회사)·`did`(걸려 온 번호)·`caller`(발신번호 — 운영사가 제공을 켠 경우만)로 판단하십시오.

⚠️ 업무 시스템 자격증명이 «하나에 토큰 하나» 방식이면 **DVG 와 같은 자격증명을 쓰지 마십시오** — 서로의 토큰을 끊습니다. 앱 전용 자격증명을 받으십시오.

## 4. 시험하기

**전화 없이** — DVG 가 등록된 앱 주소로 **실제로 연결**해 실통화와 같은 흐름을 돌리고, 발신자의 말은 여러분이 적은 글로 대신합니다:

```bash
curl -sS -X POST -H "Authorization: Bearer $DVG_APP_KEY" -H 'Content-Type: application/json' -d '{"utterances":["강남역","","서초동","착불","네"]}' "https://<DVG 주소>/api/v1/apps/self/simulate"
```

- 빈 문자열은 «무응답» 입니다. 발화를 다 쓰면 «발신자가 끊음» 으로 끝납니다.
- 시험은 **사용량에 기록되지 않습니다** · 앱당 분당 20회.
- ⚠️ **글자 시험입니다** — 음성인식 오인식·무음 판정·끼어들기는 재현하지 않습니다. 실통화의 `prompt.text` 는 「강남역**이요**」처럼 조사·군말이 붙어 옵니다.

**내 사용량**:

```bash
curl -sS -H "Authorization: Bearer $DVG_APP_KEY" "https://<DVG 주소>/api/v1/apps/self/usage?month=2026-09"
```

`found:false` 는 «0건» 이 아니라 **그 달에 아직 기록이 없다** 는 뜻입니다. 금액은 싣지 않습니다(수량만).

## 5. 체크리스트

- [ ] 서명·타임스탬프 검증(틀리면 연결 거절) — [시험 벡터](../conformance/vector.json) 통과
- [ ] 모든 메시지에 10초 안에 지시 하나
- [ ] 다시 물을 때는 질문을 바꾸고, 두 번 못 알아들으면 `transfer`
- [ ] 선택지 질문은 `choices` · `confirm:true` 면 복창
- [ ] 주소 질문은 `expect:"address"` · 여러 곳이면 DVG 의 `question` 을 그대로 · `verified:false` 면 반드시 복창 · 좌표가 필요하면 운영사에 «좌표 제공» 요청(없을 때의 처리도)
- [ ] `end` 를 받으면 그 통화 처리를 끝낸다
- [ ] `setup.simulated` 면 실제 주문을 만들지 않는다
- [ ] 로그에 발화·개인정보를 필요 이상 남기지 않는다(사이드카 로그는 운영사가 볼 수 있다)

## 6. v1 에 없는 것

- 질문마다 음성인식 힌트 바꾸기(앱 등록 단위 낱말만 된다)
- 앱이 사람 연결 번호를 지정하기 — 일부러 막았습니다
- 원시 오디오 스트림
- 대시보드 안 앱 화면
